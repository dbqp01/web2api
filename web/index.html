Un patrón con límites claros

El descubridor admite catálogos públicos con respuestas JSON y fichas de producto. No interpreta cualquier objetivo ni resuelve accesos restringidos. Requiere Chromium instalado.

npx playwright install chromium

La idea en una frase

Web2API convierte recorridos web observados en herramientas reutilizables que ejecutan HTTP y verifican cada respuesta.

Qué demostrar

La ejecución no necesita navegador, visión ni llamadas a un modelo. El contrato conserva los parámetros y comprobaciones inferidos de la evidencia.

Antes de salir al escenario

El laboratorio funciona sin servicios externos y está identificado como demostración.

npm run studio:demo

Abre http://127.0.0.1:4320. Busca un producto, confirma su incorporación al carrito ficticio y consulta el carrito. El estado se elimina al cerrar el proceso.

Recorrido de presentación

  1. Ejecuta un workflow

    En el catálogo, revisa sus parámetros y pulsa Ejecutar.

  2. Enseña el resultado y su evidencia

    Cambia entre Resultado, JSON y Evidencia. Descarga la respuesta si la necesitas.

  3. Cambia una entrada

    Repite la llamada con otro valor. El contrato sigue siendo el mismo.

  4. Conecta con otra aplicación

    Copia la llamada cURL o abre el contrato OpenAPI. Configura la clave local para clientes externos.
